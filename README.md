# SWYNEX-Data-Cleaning-and-Basic-Analysis
Data Cleaning and Basic Analysis of GSE2034 Biological Dataset
# SWYNEX Internship — Task 2: Data Cleaning and Basic Analysis

## Project Overview
This project focuses on cleaning and performing basic statistical analysis on the GSE2034 gene expression dataset.

## Dataset Information
- **Dataset:** GSE2034
- **Organism:** Homo sapiens
- **Samples:** 286
- **Probes:** 22,283
- **Platform:** Affymetrix Human Genome U133A

## Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Data Cleaning
The following checks were performed:
- Checked for missing values.
- Checked for duplicate rows.
- Checked for duplicate probe IDs.
- Examined the expression values.
- Prepared a cleaned dataset for analysis.

## Statistical Analysis
The following descriptive statistics were calculated:
- Mean
- Median
- Standard deviation
- Minimum
- Maximum

## Visualizations
Three graphs were created:
1. Gene Expression Distribution
2. Mean Gene Expression Across Samples
3. Distribution of Sample Median Expression

## Project Files
- `data_cleaning_analysis.ipynb` — Jupyter notebook containing the analysis.
- `GSE2034_cleaned_dataset.csv` — Cleaned dataset.
- `statistical_summary.csv` — Statistical summary.
- PNG files — Analysis visualizations.

## Conclusion
This project demonstrates basic data cleaning, statistical analysis, and data visualization using Python on a biological gene expression dataset.
